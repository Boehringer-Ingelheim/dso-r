# Apply watermark to an image file using the dso CLI

Apply watermark to an image file using the dso CLI

## Usage

``` r
.apply_watermark(input_file, output_file, watermark_config)
```

## Arguments

- input_file:

  Path to the input image

- output_file:

  Path to the output (watermarked) image

- watermark_config:

  List with watermark configuration
