# Execute dso repro with dependencies and display the result

This function reproduces the current stage along its dependencies and
displays the resulting report in the RStudio Viewer pane.

## Usage

``` r
dso_repro_stage_w_dependencies_addin()
```

## Value

None

## Examples

``` r
if (FALSE) { # \dontrun{
dso_repro_stage_w_dependencies_addin()
} # }
```
