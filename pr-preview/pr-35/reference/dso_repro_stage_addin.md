# Execute dso repro and display the result

This function reproduces the current stage without its dependencies and
displays the resulting report in the RStudio Viewer pane.

## Usage

``` r
dso_repro_stage_addin()
```

## Value

None

## Examples

``` r
if (FALSE) { # \dontrun{
dso_repro_stage_addin()
} # }
```
