# stage_here

get absolute path to stage

## Usage

``` r
stage_here(...)
```

## Arguments

- ...:

  additional parts of the path appended to the stage path using
  \`file.path\`

## Value

absolute path to stage

## Details

Get the absolute path to the current stage. The current stage can be set
using set_stage() by providing the relative path of the stage from the
project root directory. to the stage dir.
